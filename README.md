# Mulanshan Surge

这是 `mulanshan/surge` 的公开分发仓库，用来保持现有 Surge 模块和规则集订阅地址稳定。

保留的公开路径：

- `rewrite/Surge/*.sgmodule`
- `rewrite/Surge/scripts/...`
- `rule/Surge/*.list`
- `rule/Surge/*.conf`
- `rule/Surge/generated/*`
